# UX copy — Casa Marafo

Voz: calorosa, direta, de boteco bom — sem jargão de marketing. Português do Brasil, frases curtas.
Regra de ouro: só afirmar o que é fato (cardápio, ficha do Google, briefing). Nada de avaliações, eventos ou números inventados.

| Elemento | Copy | Por quê |
|---|---|---|
| Hero (título) | Uma experiência que merece ser vivida. | Definido no briefing. |
| Hero (status) | Aberto agora · até 01h / Fechado agora · abre quarta às 17h | Responde a dúvida nº 1 de quem procura um bar: "está aberto?". Calculado no fuso de São Paulo. |
| CTA primário | Conheça a Casa | Verbo + destino. |
| CTA secundário | Explore o cardápio | Verbo + destino. |
| Selo hero | da cana ao copo | Liga a cachaça (marafo) ao produto final. |
| Experiências — CTAs | Conhecer os drinks · Ver no TikTok · Abrir o cardápio · Como chegar | Cada card diz para onde leva, em vez de uma seta muda. |
| Drinks | A cachaça no centro do copo. | Posiciona a carta autoral; texto de apoio só com termos do cardápio (infusões, fat-wash, shrubs, soda artesanal). |
| Filtro | Só opções veganas | Rótulo de interruptor descreve o estado ligado. |
| Estado vazio do filtro | Nenhuma opção vegana em drinks por enquanto. Veja as abas Entradas, Porções e Lanches. | O que é + por que está vazio + para onde ir. |
| Galeria | Toque numa foto para ver maior. | Instrução de interação, sem "clique aqui". |
| Botões do lightbox | Fechar · Imagem anterior · Próxima imagem | Rótulos de ação para leitores de tela. |
| Barra mobile | Ligar · Cardápio · Como chegar | As três tarefas de quem já decidiu ir. |
| Rodapé legal | Beba com moderação. Venda proibida para menores de 18 anos. | Exigência para publicidade de bebida alcoólica. |

Localização: textos sem gírias regionais fora de "marafo"; preços sempre com "R$" e vírgula decimal.
